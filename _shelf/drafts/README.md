# Drafts

Pending batches written by the `drafter` subagent. Each file uses the exact header of its data table, and placeholder IDs (`<tag>-W001`, `<tag>-S001`).

Files waiting here count as known vocabulary for later drafts, so nothing gets drafted twice. After a merge, move the batch to `merged/`. The full workflow is in `_agent/SCHEMA.md`, under "Drafting workflow".
